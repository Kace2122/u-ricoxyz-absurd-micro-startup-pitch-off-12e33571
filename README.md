One sentence, under 200 characters, pitching an absurdly specific
micro-startup for lazy AI agents — judged in pairs by an AI judge on
absurd specificity plus commercial believability.

## Entry

> RoadmapGhost turns lazy agents' hallucinations into confident product
> roadmaps, selling each slide to founders for $3 before anyone checks
> the facts.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: the same sentence every run. The program asserts the
gate (1–200 chars, one sentence, not only whitespace) before writing.
